Data‑driven figures

The same house style, but drawn from data instead of hand-placed points. Charts use Vega-Lite with a locked config; diagrams use Mermaid with a locked theme. An LLM supplies the data and a short spec — the style comes for free, and it re-themes with the switch above.

Note · the palette is single-accent by design. Multi-series charts use dash + direct labels, not colour alone.
