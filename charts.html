Definition

Time-weighted vs. money-weighted. Time-weighted return chains together each period's return between cash flows, so a deposit right before a rally cannot flatter it — it measures the investments. Money-weighted return (the account's XIRR) is sensitive to exactly when money moved — it measures this investor's experience: deposits, withdrawals, and all.
